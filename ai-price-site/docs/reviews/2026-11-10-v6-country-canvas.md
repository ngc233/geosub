# V6 中文国家详情页（本地复核）

基线：0189acf4244e36d4a61841381b5588c92fe3e4be（2.30.1）。Improvement / L2。
范围仅土耳其、印度、菲律宾、日本四个中文国家详情页。按 V2 任务书 V6 与 design/canvas/source/Country.dc.html 实现；国家目录留到 V7。

## 数据与方法

读取现有 DATA-1 loadVerifiedPriceSource，再用 getCountryHubRows 按国家派生，不新增数据库查询、缓存策略、迁移或依赖。表格继续保留缺少新鲜汇率的本币行，但不为它们计算美元比较。读取失败显示安全空态，只记录事件名与错误类型。

统计以产品、套餐、平台、周期去重；每个有效美国同套餐比较等权，原始节省率 s = 1 - usd / usPrice，负数保留。调用与首页相同的 homepageCountries 计算中位数。便宜数量以 s > 0 判断，百分比仅显示时四舍五入。少于五个可比套餐时隐藏统计与中位数结论；负中位数如实显示“贵”，不渲染成省钱。

## 已批准的内容与链接边界

V2 任务书已批准国家页采用中位数 H1；其余 SEO 元数据、noindex、结构化数据不变。本轮产品负责人明确批准：仅链接现有页面，重新排布四个中文国家页的套餐、快照和历史入口，并增加现有国家页及支付与账号指南入口，记录前后差异。

价格表整行链接到原套餐页，来源与记录收拢到可展开区域；原始快照、价格历史、“比较所有地区”、分类锚点和价格探索目标保留。新增四国对照入口和 payment-account 指南入口，不新建路由、不引入礼品卡教程。精确链接数量、增量及元数据对照见复核包 regression-and-seo.json。

## 手机性能修复与复测（2026-11-10）

本轮为 Improvement / L2，仅修复 V6 手机性能差距。保持 Inter Tight 数字字体、字重、unicode 范围与 `font-display: swap`；不改全局构建配置、数据读取器、缓存政策、性能门槛或锁定页。原 3196 预览与本地 55436 临时数据库保留；验收用 3197 同库旧版和 3198 正式构建新版。

先定位再改动：Lighthouse 的 LCP 是国家页导语段落，并非价格数字。初始本地 TTFB 约 12ms；首屏资源竞争、提前下载的下方图标与套餐路由、客户端静态日期初始化更值得处理。独立诊断在四倍 CPU 限速下记录到 DateTimeFormat 初始化约 21ms；此诊断不作为性能门禁。

保留的局部优化：

- 国家页下方图标接近视口才加载。共用 BrandIcon/CountryIdentity 新增显式开启参数，默认调用行为不变；首两项产品图标仍保留原生服务端图片。固定容器尺寸、无 JS 的 noscript 图片和失败回退均保留。可见图标不会为了得分延迟到交互后才出现。
- 国家页价格行关闭自动套餐预取，实际链接和点击导航保持不变；该做法沿用 V4。前后 74 条链接的 href、rel、文字和相对顺序不变。
- 日期在服务端通过同一个现有格式化函数生成，移除客户端重复初始化；跨年、时区、无效与缺失日期逐项验证等价。
- 将同一份 4,408 字节数字子集嵌入可缓存的国家页 CSS，减少独立字体请求的加载往返，不放进 HTML，也不在运行时读文件。使用国家页专用 CSS family 别名，避免影响客户端导航后的其他页面。生成脚本复用共享声明，执行型测试核验解码后的二进制完全一致，字重、swap 和 unicode 范围也一致。全部 woff2 文件仍为 49,816 字节；本轮未重新生成字体。
