# GeoSub 前台设计稿（画布导出）

版本：2026-11-06，对应画布第 33 版。**这是前台视觉的唯一标准。**任务书与画布冲突时，以画布为准；画布与 SEO、数据规则冲突时，停下报告。

## 目录

| 路径 | 内容 |
| --- | --- |
| `source/*.dc.html` | 13 块画板的源文件。所有尺寸、颜色、间距都写在行内 style 里，直接打开文本就能量 |
| `renders/*.png` | 每块画板在指定宽度下的 1:1 截图（deviceScaleFactor 1），用于叠图对比 |

渲染图里的英文数字字体（Inter Tight）因为离线渲染没有加载，用的是系统字体代替；字号、字重、间距以源文件为准。

## 如何在本地打开源文件

源文件需要画布的运行时才能渲染交互。运行时文件**不随本包提供，也不能提交进仓库**（它属于 Claude 设计工具）。不需要交互时，直接看 `renders/` 里的截图和源文件里的 style 就够了。

## 放进仓库的位置

- 把 `source/` 和 `renders/` 放到 `ai-price-site/design/canvas/`，单独开一个只含设计文件的 PR。
- `.dc.html` 里的价格都是示例数据，不要被任何代码引用。

## 验收方式：叠图对比

每个页面任务交付时：

1. 用和渲染图相同的宽度（桌面 1280 或 1440，手机 390）截实现页的整页图，deviceScaleFactor 1。
2. 和 `renders/` 里对应的图叠在一起（50% 透明度或差值模式）。
3. 逐个区块写"一致"，或者"不一致 + 原因"。原因只能是：真实数据长度不同、SEO 锁定、已登记的产品负责人决定。
4. 区块位置偏差超过 8px、字号或颜色不同，都算不一致。

## 全局交互状态

- **卡片**：悬停上浮 2px，阴影 `0 10px 24px rgba(21,23,26,.08)`；按下缩到 98%。
- **表格行**：悬停只变 #F8FBEF 底色，不上浮、不加阴影。
- **输入框**：内层 input 没有 outline；外层圆角容器聚焦时边框变 #4D7C0F，再加 1px 同色外描边。
- **键盘焦点**：3px #4D7C0F outline，偏移 2px。
- **动效**：反馈 120ms、切换 220ms、数据 480ms、进场 320ms（间隔 40ms），曲线统一 `cubic-bezier(0.2,0.8,0.2,1)`；减少动态效果时全部瞬间切换。
