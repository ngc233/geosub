# 流量 PV 与会话读模型修复

类型：Bug / L2。基线：生产提交 `ad71456c3d50bdf89ad64d7ec4e10e714b6cec5d`。

## 已批准范围

无 Cookie PV 继续作为主指标。分类计数之和与原始计数一致时显示 eligible，未分类非零只排除自身；显示自动化、内部、未分类排除数。周期仅合计可用日期，标明覆盖 X/Y 天及缺失原因，全部缺失才显示“—”。不完整周期不计算 PV 环比。

会话按 `(anonymous_id, session_id)` 组合去重。UV、Sessions 和可比样本 PV 只使用同一批标识完整的 event_logs，缺标识事件单独计数；全无完整标识时 UV/Sessions 保持不可用，不推算会话。主卡明确注明同意统计的样本；只在样本内部满足 PV ≥ Sessions ≥ UV，不与无 Cookie PV 比较。测试路径与来源排除规则保持不变；历史事件没有内部访问分类，不承诺完整排除内部或自动化访问。

PV 缺字段单独降级，保留其他指标并显示原因。CSV 同步保留零值、缺失原因、排除数和样本口径。读模型快照版本升为 2，避免把旧快照的单会话 ID 去重误标为组合去重；旧预生产快照需要重新生成，不改变数据库 schema 或写入协议。

不修改统计写入、已有生产数据、历史回填、依赖、缓存、发布机制、受保护规则或页面布局。

用户明确要求：以后任何生产数据库查询，即使只读，也必须先说明查询内容、取得当次确认再执行。本次实现与验收没有新增生产数据库查询。
