日期：2026-10-28（北京时间）。状态：第 11 节为最新视觉优先决定及本地实施验证；待视觉评审，未提交、未推送、未部署。
类型：Improvement；L2（共享导航、多页面行为与共享组件）。不含数据模型、迁移、公开页面或权限语义变更。

本文件承接 [后台整体升级 RFC](rfc-admin-upgrade-2026-10-15.md) 中“全后台产品审查”P2 的导航整合项，以及 [六模块实施清单](geosub-six-modules-current-state-and-backlog-2026-10-26.md) E1“六个工作入口及产品内聚合导航”。只重组已有能力，不新增业务能力；**保留 2026-10-15 已确认的视觉风格**（深色卡片、主色、排版、明暗主题）。

## 2. 目标与不变项

目标：每个正式页面可从导航到达；一项事务只有一个主页面；数据页可检索、可分页；写操作集中、可确认；同一视觉通过令牌表达。

不变项：现有 URL 与深链接全部可用（只调整入口与页面组成，旧地址保持或 308 到等价视图）；服务端 read/draft/manage/account 权限；数据口径与状态判定；采集、审核、发布的业务规则；公开站点；真实推广关闭。

## 4. 三种页面模板

### 4.1 列表页（产品、套餐、正式价格、采集队列、待审核、工单、文章）

```
┌ 标题 · 一句话用途 ─────────────────────────── [主操作] ┐
│ [搜索…]  [状态 ▾] [分类 ▾] [平台 ▾]  已筛选 3 项 · 清除    │  ← 全部写入 URL
├──┬──────────────┬──────┬──────┬──────┬────────┬──────┤
│☐ │ 产品          │ 发布  │ 数据  │ 采集  │ 最近核验 │      │  ← 表头可排序、吸顶
│☐ │ ChatGPT       │ 已发布│ 正常  │ 运行中│ 10/28   │ 查看 →│
│☐ │ Disney+       │ 已发布│ 1 过期│ 已配置│ 10/12   │ 查看 →│
└──┴──────────────┴──────┴──────┴──────┴────────┴──────┘
  第 1–50 / 3,733 条            ‹ 1 2 3 … 75 ›   每页 50
  ── 选中后底部出现：已选 2 项 [加入采集队列] [取消]  → 确认对话框写明对象与影响
```

服务端分页与筛选（只读查询，不改口径）；空、加载、错误、无权限四态统一；行内只放“查看”，写操作走批量栏或详情页。

### 4.2 产品工作区（单产品详情）

```
┌ ‹ 产品  ChatGPT · OpenAI         [发布:已发布][数据:正常][采集:运行中] ┐
│ 概览 | 套餐 | 来源与采集 | 价格 | 内容 | SEO            ← 页签写入 URL │
├───────────────────────────────────────────────────────────────┤
│ 当前页签只做一件事；该页签的操作放在页签标题右侧                         │
│ 例如“价格”：本产品价格表（同 4.1 模板，限定 product）                    │
└───────────────────────────────────────────────────────────────┘
```

复用现有产品、套餐、来源、SEO 表单与其事务/版本保护，不重写保存逻辑；危险操作二次确认。

### 4.3 队列页（工作台；审核与数据质量复用同一组件）

```
┌ 今日待办                     [需要处理 3] [执行中 4] [全部]  ┐
│ ● 阻塞  Apple Music   尚无 App Store 正式价格   来源时间  [处理 →] │
│ ● 过期  Disney+       1 条价格超 14 天未核验    10/12     [处理 →] │
└─────────────────────────────────────────────────────────┘
```

一个队列组件、一套排序（阻塞 > 影响 > 等待时间）；工作台、数据质量、流水线只是不同的预设筛选，消除三处重复实现。

## 5. 文案与操作规则

- 页面标题下最多一句用途说明；数据范围/口径说明收进标题旁“说明”展开或提示气泡；状态用徽章表达。
- 保留显式警示的情况：不可逆操作、影响正式数据或生产的操作、数据不可用/未知。
- 列表不放逐行写按钮；写操作在批量栏或详情页，确认对话框列出对象、数量与后果；服务端权限校验保持不变。

## 6. 视觉令牌（不改外观）

在后台作用域（`data-admin-theme`）新增 CSS 变量：surface / surface-raised / border / text / text-muted / accent / success / warning / danger / info，**取值等于当前使用的 slate/blue/amber/emerald/red 实际颜色**，明暗两套。先迁移共享组件（Card、Table、Badge、Button、Input、Select、Alert），再随各批页面迁移；为已迁移文件加静态测试，禁止新增原始色板类。迁移前后同页截图对比，不接受肉眼可见变化。

## 10. 第 1 批实施记录（2026-10-28，本地）

实现：

- `app/globals.css` 新增后台中性色令牌（canvas、surface、border、text 系列、accent、shadow 等 16 个），取值即原 slate/blue 色阶，明暗选择与自定义 dark 变体一致。共享组件 AdminCard、AdminTable、AdminInput、AdminBadge（draft/neutral）、AdminButton（secondary/ghost）、AdminMetricCard、后台布局与侧边栏的中性色改用令牌；状态色、悬停文字色仍为色板类。AdminSelect、AdminAlert 未迁移（AdminAlert 目前没有暗色样式，属于既有缺陷，迁移会改变外观，留到第 5 批）。
- 列表模板：`lib/admin-list-params.ts`（URL 参数解析、白名单排序、页码夹取、链接构造）及 `AdminFilterBar`、`AdminDataTable`（排序表头、吸顶、空态、分页）、`AdminSelectAll`、`AdminBulkActionBar`（批量栏与原生 dialog 二次确认，复用 AdminActionForm 权限与提交反馈）。本批未接入任何页面，从第 2 批开始使用。
- 导航按第 3 节分为 工作台 / 产品目录 / 价格数据 / 内容与增长 / 运营 / 系统 六组；“产品流水线”更名“采集与审核”并仍为唯一采集入口，审核、线索、采集任务、价格观测旧地址都高亮该项；高亮改为按路径段匹配。

## 11. 视觉优先的新决定（2026-10-28）

用户明确指出后台视觉、页面效率与操作流程均有问题，当前先完成视觉优化，工作流另行设计。本节取代第 6 节“视觉不变”的约束；第 10 节零差异记录仅对应首次颜色变量迁移，不适用于后来参考图样板或本轮统一。

本轮分类：Architecture / L2（后台设计系统与多页面视觉），以用户提供的浅灰底、轻卡片、蓝色选中态参考图为方向。统一后台共享组件和已有页面的中性色、字重、标题、卡片及状态标签；补齐暗色与窄屏。颜色变量限定在后台主题作用域。保留用户与 Claude 的已有修改，不改查询、服务端写入、权限、发布或采集规则。

视觉标准：页面标题桌面 24px / 手机 20px，字重 600；正文 14px，标签与辅助说明至少保持可读对比；卡片 16px 圆角、轻阴影，控件 8px 圆角；状态使用柔和底色与清楚文字，文字和颜色遵循同一状态优先级；禁用无层级的 800/900 超粗字重。所有后台页面复用同一中性调色板，不通过全局 !important 覆盖业务控件。

验收：相关自动化、类型、Lint、构建；工作台、产品库、购买力、表单/数据页代表页面的桌面与 390px 明暗主题、可见焦点、标签不竖排、无页面级横向溢出。旧业务流程的调整不作为本轮交付条件，后续单独定义新工作流。

回退：本轮改动前的目标文件快照保存在工作区外侧的 ui-visual-backup-20261028，仅恢复本轮修改；不得使用 Git reset 清除 Claude 已有的未提交改动。完成状态与实际验证结果追加在本节后，不沿用旧截图和测试结论。

### 正式价格版本语义

由正式发布事务自动记录编号、提交时间、作用平台、变化摘要和可追溯原因；不靠人工改文件。

仅同价复核且正式内容与公开资格均不变时，更新核验时间，不递增价格版本。
价格、币种、周期、平台、正式来源、公开折算值或公开资格变化时应产生新版本。
来源汇率表刷新但尚未改变公开价格时不递增；采用后的公开折算变化按正式数据规则记录。
产品/套餐/地区必须使用稳定身份，Web 与 iOS 分别统计，不能按显示名称匹配。

同一发布事务或明确批次生成一份记录，不为每行价格生成一版；并发分配必须唯一且不丢失。
事务失败不留下“发布成功”版本；必须覆盖自动审核、人工审核、正式数据编辑和上下架入口，
不能仅挂在采集结束回调，否则网站操作会绕过数据编号。
首版建档从真实当前状态开始，不补造上线以来的历史编号或来源时间。
版本记录表示可追溯变化，不承诺已经保存全部历史数据快照，也不提供数据库恢复按钮。
