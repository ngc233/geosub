# GeoSub 信息架构与页面模板

状态：v2.10 规范基线  
生效日期：2026-08-25

## 1. 目标

GeoSub 必须被视为少数稳定页面模板组成的产品，而不是一组独立设计的页面。新增内容优先映射到现有模板，不为单个产品创建新的全站结构。

## 2. 当前公开页面层级

### 2.1 首页

路径：`/[locale]`

职责：解释 GeoSub 的价值、展示代表性全球价格差异，并把用户引向已发布的分类和产品。

必备模块：

- 产品价值与核心任务。
- 代表性产品切换与全球价格摘要。
- 已核验数据规模和更新时间。
- 分类入口、方法说明与可信度入口。

首页不是完整价格表，也不是自动轮播营销大屏。

### 2.2 分类页

当前路径：

- `/[locale]/ai-pricing`
- `/[locale]/streaming-pricing`

职责：帮助用户发现分类内产品，并预览每个产品当前主流套餐的价格范围。

每个产品卡只展示一个有明确口径的主流套餐。不得把不同平台或不同计费周期的极值拼成一个范围。

### 2.3 产品概览页

路径：`/[locale]/ai-pricing/[product]` 或 `/[locale]/streaming-pricing/[product]`

职责：解释产品定位、已收录套餐及其差异，引导用户选择套餐。

产品页不重复套餐页的完整地区表。只有一个可发布套餐时，也应保持产品概览与套餐详情的职责区别。

### 2.4 套餐价格页

路径：`/[locale]/ai-pricing/[product]/[plan]` 或对应流媒体路径。

职责：提供一个套餐在一个明确计费平台上的全球价格结论、地区明细、证据、购买力和相关决策内容。

标准区块顺序：

1. 返回路径、产品身份、H1 和简要结论。
2. 套餐切换与产品概览入口。
3. 价格结论、币种、最低价、最高价、基准和新鲜度。
4. 全球分布与地区排行。
5. 地区价格表、筛选、比较和证据。
6. 套餐适用人群与主要差异。
7. 价格位置与购买力。
8. 相关地区分析、相关产品、方法和 FAQ。

不适用或没有合格数据的区块必须完整降级或不显示，不得保留空卡片。

### 2.5 地区分析页

路径：`/[locale]/.../[product]/regions/[country]`

职责：解释一个产品在特定地区的价格、来源、税费、时间和相对基准位置。

地区页必须有独立价值，不能只是套餐表中一行的放大版。地区页面数量受 SEO 质量门槛和 sitemap 预算控制。

### 2.6 指南与文章

路径：`/[locale]/guides`、`/[locale]/guides/[slug]` 及分类、标签页。

职责：解释价格方法、支付与账号背景、工具使用和具有证据的专题。指南与价格页通过真实相关性双向链接。

### 2.7 工具

当前正式工具：`/[locale]/tools/currency-converter` 及货币对页面。

工具必须完成一个明确任务，具备输入、输出、错误、空态和数据日期。不得仅为 SEO 创建不可用的工具入口。

### 2.8 报告

路径：`/reports/[locale]/[filename]`

职责：提供基于规范数据集生成、可引用、带版本和来源的价格报告。

报告数据必须与网页读取同一 canonical dataset，不允许截图当前 DOM 代替数据生成。

### 2.9 内部页面

`/admin`、测试页、追踪页和未发布专题属于内部或受控页面。必须明确认证或 `noindex`，不得进入公开导航和 sitemap。

## 3. 全站导航

全站导航只包含稳定、已发布的一级任务：主页、数字订阅分类、指南、数据来源、搜索和语言切换。

导航规则：

- 不为尚未完整发布的分类创建一级入口。
- 移动端和桌面端信息架构一致，只改变呈现方式。
- 同一目标在一个视觉区域内只保留一个主要入口。
- 外部官方链接必须使用标准外链图标和安全属性。

## 4. 候选能力边界

独立 Compare 页、历史价格页、软件、游戏、礼品卡和 API 门户目前不是默认正式模板。它们必须先通过 PRD、数据可用性和 SEO 重复风险评审，才能加入本架构。

现有页面中的地区比较交互不等于已经批准独立 Compare 路由。

## 5. 响应式策略

- 桌面端可以并排展示地图、摘要和价格列。
- 移动端采用纵向信息卡、横向可滚动的短控件和底部详情层。
- 触控设备不依赖 hover 才能访问信息。
- 移动端不强塞不可读的全球地图标签或完整宽表。
- 任何断点下不得出现页面级横向溢出。

## 6. 模板变更规则

修改页面模板前必须说明：

- 受影响的页面类型和路由数量。
- 用户任务是否改变。
- SEO、结构化数据和内部链接是否改变。
- 桌面、移动、亮色和暗色的设计状态。
- 空态、失败态、加载态和数据不完整态。
- 迁移方式与回退方式。

单页视觉问题不得通过复制模板解决。
