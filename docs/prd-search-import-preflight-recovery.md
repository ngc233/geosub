# 搜索页面报表预检与同窗口恢复

类型：Feature / L2。授权：实现、夹具验证、推送、CI 后标准网站滚动上线。此记录不代表已发布。

## 问题与方案

既有页面报表导入静默丢弃异常行和第 501 页以后的记录；同引擎同窗口替换后，撤销仅删除新批次，丢失原版本。

- 浏览器纯计算预检，显示原始/有效/排除/合并/最终页面数、逐行原值与原因，识别关键词表与列错误。精确整数、合法日期、域名、路径和排名校验；超 500 个有效页整份拒绝，不截取。排除行需明确确认。
- 编辑后预检失效；服务端重复相同预检并核对输入摘要。预检不读写审计或数据库，管理权限只在实际提交时执行。
- 复用 site_settings 与 audit_logs，定位最近批次的原始 import 审计。验证完整 old/new 快照及追加关系；只恢复该引擎该窗口被覆盖版本。首次导入撤销只移除该窗口。缺失、损坏或不一致的审计拒绝恢复。
- 在页面先显示恢复范围；恢复新增审计并记录依据，不编辑历史审计。事务内获取同设置 advisory lock，核对页面版本并原子写状态与审计，防止并发覆盖。过期/失败保留输入。

## 边界与验收

不实际导入、撤销或修改生产数据，不新增来源、不抓取、不提交搜索平台。保留标题、中文 Plus 实验锁和全部公开页面；不改采集任务、依赖、数据库结构、定时器或发布控制器。

合成 CSV、审计快照和隔离本地 PostgreSQL 验证：77→76/45→44 的路径排除；查询表拒绝；501 页完整拒绝；约数、异常计数、重复路径与缺失排名；A→B→C 连续恢复、跨引擎/窗口隔离、损坏/缺失审计、并发过期版本与审计原子性。浏览器覆盖四种尺寸/主题、输入修改后失效、排除确认、错误、空态、权限和恢复预览。

通过标准 release-check 与 CI 后仅 web-upgrade；数据库输入不变由控制器跳过迁移。生产只读验证导入设置/审计不变、Plus 输出与锁不变、网站和采集运行健康。代码回退保留已有审计数据，不执行数据库恢复。
