# 其他产品各语言 PDF 检查与来源链接修复

Bug / L2；按用户授权在验证与CI通过后执行L3标准无停机网站发布。

范围：检查除ChatGPT/Spotify外35个正式产品的12语言PDF，共420份，重点核对长套餐名、税费说明、来源地址、分页页脚。已确认现有PDF仅打印URL，没有Link注释；部分阅读器无法点击来源。真实12语言回归在修复前全部失败。

修复只为已存在的来源URL和封面canonical页面/报告URL增加标准PDF链接注释；换行、跨页的每一行指向原始完整URL。仅允许无凭据、无空白的HTTP(S)地址；缺失和非法来源仍保留原文但不变成可点击链接。不猜测或补写汇率提供方地址。

不变：canonical价格、套餐/税费/来源内容、报告与页面标题、字体/版式、中文Plus实验、全部采集组件/任务/定时器、数据库与索引范围。其他排版问题仅在真实报告证据确认后修复。

验收：420份发布前/后报告逐页结构与文字/金额比对；对全语言代表报告渲染检查，长套餐名/税费密集页/来源换行与尾页抽检；真实注释目标及矩形边界核验，缺失/非法URL不产生链接。既有分页与混合文字回归、完整release-check、四组CI通过后按geosub_ops标准网站发布；数据库输入不变则跳过迁移和任务暂停，保留2.15.10构建并登记精确内容兼容回退对。

发布前实际结果：420份公网报告/3463页完整检查，缺字、正文越界、页眉页脚、空白尾页问题均为0；420份均无链接注释。35产品各选一张税费密集表格页渲染检查，覆盖全部12语言。复用既有公开读模型离线生成420份候选，套餐名/税费全文、实际字形覆盖、所有定高文字容器均通过，canonical输入未修改；pypdf逐份解析确认实际链接目的地与原始来源/封面URL相同且矩形在页面内。新旧回归60例及完整release-check通过（新基线重新执行也通过）。
