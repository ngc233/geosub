## 1. 选择方法

本轮没有把产品和国家机械相乘。候选需要同时具备：

- 已发布、已核验的 App Store 月付价格，且套餐身份明确。
- 产品或套餐已在 Google、Bing 或站内搜索中出现需求信号。
- 国家本身存在可信价格事件、显著地区差异或值得解释的套餐结构。
- 页面可以写出当地价格、税务、可用性和购买决策信息，而不只是替换国家名。

站内 90 天搜索只有 7 次、5 个词，样本不足以单独证明市场需求，只作为弱旁证。Google 与 Bing 的数据是页面级观察，也不能假装成国家关键词量。因此本清单保留明确的发布前复核门槛。

## 3. 暂不入选

- Gemini 土耳其：同一商品名出现多个价格，周期或 SKU 尚不能确定。
- Grok 印度：`SuperGrok` 同名出现 INR 2,900 和 INR 29,000，不能猜测档位。
- Claude Pro 韩国、以色列、泰国的旧变化：历史商品名为 Annual，当前证据为 Monthly，不能比较。
- ChatGPT 和 Claude 哥伦比亚高价：价格差异虽大，但本轮没有完成新的官方页面身份重放，不作为首批试点。
- Netflix Pakistan：低价信号明显，但 Basic 的新用户可用性和当地订阅条件尚未达到首批内容门槛。

## 4. B2 进入条件

每个候选在创建页面前必须形成独立事实卡：

- 当前各套餐本币价格、周期、采集日期和官方来源。
- 当前汇率与汇率日期，且不把折算变化写成调价。
- 税务资料、可信等级和最终结算提示。
- 账号地区、支付、商店可用性和套餐限制。
- 与美国基准、全球位置及相邻地区的可解释比较。
- 至少一段该国家独有的决策说明。

首批页面先保持代码级关闭或 `noindex`。完成中文内容、桌面和移动端验收、结构化数据检查及重复度检查后，才提交 P0-C 的索引预算审批。

## 5. B2 关闭式预览

首批 7 个候选现已建立中文和英文预览路由。预览只接受本清单内精确的产品、分类和国家组合，并执行以下门禁：

- 页面保持 `noindex,follow`，不进入 sitemap，也不声明 hreflang。
- 价格读取现有正式价格库，不复制或写入第二份价格数据。
- 页面分别展示本币标价、美元参考、价格采集日期和订阅前限制。
- 未列入白名单的组合返回 404，防止产品与国家机械相乘。
- Netflix 印度页仍属于关闭式预览，Basic 新用户可用性未核清前不得开放索引。

事实卡、移动端和内容门禁已完成，并已接入 P0-C 只读发布体检。当前本地批准名单为 Claude 韩国、Grok 韩国、ChatGPT 菲律宾和 Gemini 日本；其余 3 页保留关闭式预览。下一步是单独批准首批索引范围与 sitemap 预算，不批量生成更多页面。
