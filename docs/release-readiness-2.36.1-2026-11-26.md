# GeoSub 2.36.1 发布准备

版本从 `2.36.0` 递增到 `2.36.1`。基线为当前线上及 `main` 提交 `763541e51e979e657c8fdad50d443a2b9b4f45ef`（GeoSub 2.36.0）。

## 发布范围

- **多游戏动态架构与数据层泛化**：将原硬编码 `/zh/games/gta-6` 迁移为动态路由 `/zh/games/[slug]`，新增可扩展游戏元数据注册表 `lib/game-catalog-meta.ts` 并泛化 `lib/read-game-offers.ts` 与 `lib/site-navigation.ts`，支持后续在数据库发布任意 `category = 'game'` 产品后自动接入目录、详情与全局搜索；原有 `/zh/games/gta-6` URL 与 `/api/games/[slug]/offers` 读接口及后台审核工作流 100% 保持兼容。
- **中文游戏目录与详情画布重构（对齐 `2.36.0` 设计系统）**：
  - **一级目录页（`/zh/games`）**：修复嵌套 `<main>`，新增顶栏平台分段筛选与全站统一 25 币种切换器 `PublicCurrencySelect`；收录 `<= 2` 款游戏时采用通栏横版旗舰卡（左侧封面与最低区服摘要 + 右侧全行可点击版本对照矩阵），`>= 3` 款时自动切换双列网格。
  - **二级详情画布页（`/zh/games/[slug]`）**：移除旧版背景叠图、粉紫径向发光、荧光绿边框、吸顶二次章节栏及独立 3 币种弹窗；升级为 H1 同行凹槽键帽切换器（`PS5 | Xbox | PC 待官宣` 与实时折算价版本键帽）、双栏等高核心结论卡（全区最低总览 + 同平台版本差价对照，升级包仅在存在有效可购报价时按需展示）、6 列官方商店比价表与原生画布手风琴 FAQ。
- **全站壳层闭环**：全局搜索（`/api/search` Chrome 索引）纳入已发布游戏的买断最低价；移除中文首页首屏冗余 `GTA 6 港服比价` 独立胶囊按钮，统一通过「按分类找 → 游戏」圆角方形图标卡片与导航栏/页脚「价格数据 → 游戏比价」分流；收敛 `/zh/games*` 可用语言列表，消除无效多语言预取 `404`。
- **不变项与冻结边界**：中文 ChatGPT Plus 实验页（`/zh/ai-pricing/chatgpt/plus`）、英文页面及锁定页路由、canonical、robots、JSON-LD 与订阅价格计算口径均保持原样。
