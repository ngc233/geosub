# Spotify 官网采集、自动审核与发布

Feature / L3。用户要求先核对缺少官网采集器的产品，选公开价格清楚的一项接通全自动闭环；异常隔离，不逐条人工审核，前台持续可访问，已有任务保持运行。

## 已核对的范围

生产只读盘点：GLM、CatCosplay、Spotify 采用 official_page_only 且没有任务；Apple Music 已有暂停的试点与 pending 样本。Spotify 美国公开页面提供明确的结构化套餐身份、地区与后续月费，选它先行。只使用已有 Individual / Family 月付套餐、US / USD / Web / list_price，不扩充其他套餐或地区。

## 自动规则

- 只解析 https://www.spotify.com/us/premium/ 返回的 __NEXT_DATA__ 定价组件；校验 market/country、两个 canonical planId/planIdentifier、recurring 标识和显式月费。试用价格不作为正价，额外套餐不映射。
- HTTP 错误、地区重定向、套餐缺失、年付、多个后续价格或结构变化保存异常证据；不生成正式价格，不覆盖最后有效价格，不形成强制人工队列。
- 白名单来源的最新三个独立采集样本须同价、同币种、同套餐/周期，间隔至少 6 小时、跨度至少 24 小时，且证据在 7 天内。重复调用不能凑样本。
- 相对现有 Web 正式价格变化超过 30% 时，需要五个稳定样本、跨度至少 72 小时；异常值保持隔离，后续足够正常样本自动恢复。
- 仅精确 Web 平台键写入 region_prices；审核记录样本 ID 与规则版本。绝不调用有跨平台回退语义的旧通用批准函数。
- 完整市场的全部目标套餐通过才允许首次发布产品；不修改 ChatGPT、中文 Plus 实验、其他来源策略、站点索引或推广名单。

## 发布与恢复

实现不改变表结构或现有数据库函数。新增组件代码经聚焦测试、真实隔离 PostgreSQL 测试、相关全量门禁和 CI 后，按标准采集组件发布。任务配置是单独、幂等且限 Spotify 的事务，先有可验证备份；运行中的批次完成后再切换，不中止任何现有采集进程。

首次自然观察不伪造历史样本；自动发布必须等待真实的时间门槛。前台官网口径核验是公开前置门禁，不能把 Web 价格描述为 App Store。已有任务配置、网站进程/代理、中文 Plus 页面锁与 sitemap 推广范围作为验收不变项。

已确认的必要集成：共享价格文案只在默认来源为 Web 时改用 Web 标签并移除 Apple ID 条件，App Store 输出保持原样；后台主流程与数据质量页独立读取该试点的 Web 任务、正式价与状态，保留原 iOS 统计。官网发布使用当前网站私有构建预览密钥派生的 job-bound HMAC，向既有 loopback revalidation 路由提交 Spotify 精确任务；网站核对任务来源后刷新该产品及已有列表缓存，再生成报告。旧后台随机令牌保持兼容。只有美国一个地区，沿用当前有效地区不足的 noindex/sitemap 质量门禁，不调整推广名单。

## 验收与回退

- 正常官网实时 dry-run 得到 Individual、Family 两个套餐，证据对应官网后续月费。
- 自动审核覆盖三样本稳定通过、短重试拒绝、缺证据/币种/周期/价格变化拒绝、异常后自动恢复、大幅调价延长观察、来源/平台隔离、重复执行幂等。
- 实际 PostgreSQL 验证观察→审核→published price/plan/product，异常留存、现有 iOS 与其他产品逐字节不变。
- 配置默认 dry-run，执行仅创建/更新 Spotify 精确任务；恢复只暂停本新增任务及回退采集组件，不恢复数据库、不重启网站。保留采集与审核证据。
- 官网发布的页面与报告、后台状态和最后检查时间一致；缺口和未完成项明确说明。

## 候选验证记录

候选 2.15.0：本地标准 release-check（以 origin/main 为基线）通过；743 项前端测试全部通过，真实隔离 PostgreSQL 与官网自动化测试 21 项全部通过。受影响的产品、套餐、来源与两张后台页完成桌面/390px、亮/暗色 24 个浏览器页面状态检查，均 HTTP 200、无页面异常或横向溢出，键盘焦点与 reduced-motion 通过；受保护的实际 HTTP 刷新入口合法请求 204，未授权与任务篡改请求 404。首次/异常/恢复状态另有实际数据库与模型测试。验收数据库中的跨日样本是本地夹具，绝不转入生产。

发布顺序为网站滚动升级、采集组件升级，再在独立备份后的配置窗口创建 Spotify 唯一任务。无数据库输入变更，跳过迁移；已有任务自然完成后切换采集代码，保留定时器原启用状态。产品保持 review，直到三个真实采样时间满足自动规则；生产部署和首次自然采集结果另行记录，不以本地验证代替生产完成。
