## 已确认问题

- Canva、Notion 是草稿软件产品。2.13.0 正确阻止无 canonical spec 的名称猜测；此前生成的素材包/多语言重复套餐仍在库中，无正式价格。缺 spec 是配置前置条件，不是网络瞬断，不能移除保护或伪造价格合理范围。
- ChatGPT、Claude、Gemini 旧官网任务 job_type=price_check，runner 只接受 ai_pricing/streaming_pricing，长期不被选中。兼容范围仅限 price_check + official_site，其他任务类型不放开。
- runner 完成子任务后仅输出失败计数，不传播失败退出，导致外层 system_task_runs succeeded 与子任务失败并存。
- 健康报告缺少任务成功时效、迟到任务和未恢复子任务检查，并仍可能读取旧 checkout / 旧 web unit，需以 rolling-state 中实际 active release 为准。
