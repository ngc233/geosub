# GeoSub P0 设计确认：价格事件与国家页试点

状态：P0-A、P0-B 已完成；P0-C 发布体检已落地，4 页达到本地批准条件但尚未进入生产索引
范围：P0-A 价格事件候选、P0-B 国家页试点、P0-C SEO 发布门禁
原则：数据权威优先，先只读演练，候选不自动发布，页面不机械扩张

## 0. 验收入口与数量口径

国家分析页使用 `/regions/` 路径，不使用 `/country/` 或 `/events/`：

- 中文示例：`/zh/ai-pricing/chatgpt/regions/philippines`
- 英文示例：`/en/ai-pricing/chatgpt/regions/philippines`
- 产品总览页和套餐详情页均提供“地区价格分析”入口。

当前共维护 7 个产品国家试点组合，其中 4 个通过精确索引白名单。每个批准组合只生成中文和英文两个索引 URL，所以 sitemap 中共有 8 条 `/regions/` URL；其余 3 个组合可预览但保持 `noindex,follow`，不进入 sitemap。

本地 sitemap 口径为 `146/148`。其中汇率换算器及货币对页面是 P0 之前已经存在的产品功能，不属于本轮抢跑内容；本轮只把国家页独立预算增加为 8，并同步更新应用与部署检查的总预算。P0-A3 仍按既定决策保留为只读报告，不新增后台候选库入口。

## 1. 已确认的现状

GeoSub 已具备以下能力，本轮不重复建设：

- App Store 地区价格采集、正式价格和历史观测。
- 价格异常隔离、稳定性复采和自动审核。
- 地图、最低与最高地区榜单、税务说明和购买力分析。
- `click_country`、`click_official` 等事件及现有转化漏斗。
- 中文和英文索引、sitemap 总量预算及套餐页分批推广机制。

本轮补齐的不是另一套采集或统计系统，而是把已有数据组织成可审计的价格事件候选，并用少量原创国家页验证搜索价值。

## 2. 明确不做

- 不把汇率变化写成产品涨价或降价。
- 不把异常观测、缺失地区或过期数据写成价格事件。
- 不自动发布文章，不自动提交搜索引擎，不自动扩大 sitemap。
- 不生成“产品 x 国家 x 语言”的页面矩阵。
- 不提供虚假地址或规避平台规则的方法。
- 不把 Google Play 最低/最高应用内购买价推断为具名套餐。
- 本阶段不建设 VPN 实测、AI 排行或大型礼品卡商家市场。

## 3. P0-A：价格事件候选

### 3.1 比较身份

只有下列维度完全一致的观测才可以比较：

- 产品
- 套餐
- 国家或地区
- 计费平台
- 价格类型
- 本币币种
- 计费周期

事件判断使用本币标价。美元折算只用于解释影响，不参与“是否调价”的判定。

### 3.2 候选类型

- 本币涨价
- 本币降价
- 已核验最低价地区变化
- 套餐开始或停止在某地区提供
- 税务或订阅条件发生可验证变化

汇率变化可以形成分析提示，但不得成为价格事件。

### 3.3 证据门槛

候选至少满足以下一种条件：

- 两轮独立采集得到相同的新本币价格，并且旧价格有正式记录。
- 一条可追溯的高可信官方证据，且套餐、国家、周期和币种均能确定。

最低价地区变化还必须保证：

- 新旧地区价格均已核验且未过期。
- 比较范围一致。
- 变化不是由数据缺失、来源下线或异常隔离造成。

### 3.4 候选状态

- `detected`：发现变化，尚未满足证据门槛。
- `eligible`：证据完整，可以进入编辑判断。
- `rejected`：汇率波动、解析错误、异常数据或无实质变化。
- `used`：已用于国家页或价格事件内容。

状态仅用于候选工作流，不改变正式价格审核状态。

### 3.5 第一阶段实现边界

先基于现有 `price_observations`、正式地区价格和审核信号生成只读候选报告。第一轮不新增生产表、不写入候选状态、不改采集规则。

只读演练需要回答：

- 最近 30 至 90 天会产生多少候选。
- 其中多少只是汇率波动、异常值或重复观测。
- 同一变化是否被重复产生。
- 是否存在套餐、周期或币种错配。

只读结果通过人工抽样后，再决定是否引入持久化候选表。

本地只读演练命令：

```bash
cd ai-price-site
npm run report:price-events -- --days=90 --baseline-days=365 --limit=50
```

需要留档或进一步抽样时可追加 `--json`；只检查单个产品时可追加
`--product=chatgpt`。脚本使用显式只读事务和查询超时，结束时始终回滚，
不会写入正式价格、审核状态或内容表。

### 3.6 P0-A1 本地演练记录

2026-08-16 在本地 PostgreSQL 数据副本上完成首次只读演练。该次快照：

- 扫描 30,100 条历史观测。
- 排除 3,259 条异常观测和 18,068 条已忽略或已拒绝观测。
- 识别 773 组只有美元折算发生变化、本币未变化的记录，不建立调价事件。
- 46 个地区级变化被聚合为 11 个编辑事件组，避免同一批全球调价重复出现几十次。
- 其中 5 个事件组达到整组证据门槛，6 个保持 `detected`，没有任何内容自动发布。

演练过程中先后修正了两类误报：审核系统已明确忽略的观测不得因重复出现而重新获得资格；自动审核通过不等于独立的单条官方证据。单条证据捷径现在只接受没有自动审核理由码的人工核验官方记录。

P0-A2 需要继续抽样核对 5 个完整事件组的原始套餐名称、SKU 或页面证据，重点排除套餐映射变化和促销档位切换。在该抽样完成前，事件组只能用于诊断，不能用于国家页选题或公开内容。

P0-A2 已于 2026-08-16 完成，详细证据见
`docs/seo-price-events-country-pages-p0-a2-evidence.md`。套餐身份和同名多价门禁将可继续评估的范围收敛为两个事件组：Claude Max 5x 韩国，以及 SuperGrok Lite 韩国与泰国。其余候选继续保持拦截或观察。

### 3.7 P0-A3 持久化决策

P0 暂不新增价格事件候选表，也不增加新的后台入口。原因如下：

- A2 最终只留下 2 个可信事件组，现有只读报告足以完成复核。
- 候选目前不自动发布，也没有多人协作、状态流转或长期积压需求。
- 过早增加表、队列和后台页面会制造第二套审核工作流，与“采集和正式价格仍是唯一数据主线”的原则冲突。

当前审计载体固定为：只读报告、A2 来源证据记录和后续 B1 选择清单。只有出现以下任一条件时，才重新评估持久化：

- 同时存在至少 20 个仍需处理的可信候选。
- 候选需要多人认领、编辑决策、撤回或复用状态。
- 需要按日增量运行，并可靠区分新候选、已使用候选和重复候选。
- 国家页试点证明价格事件能持续带来搜索或转化价值。

这项决策可逆，不影响以后增加候选表；当前不做数据库迁移，也不改变生产数据。

## 4. P0-B：国家页试点

### 4.1 页面规模

第一批总计 6 至 8 页，不按产品和国家做笛卡尔积。优先从 ChatGPT、Claude、Gemini、Netflix 中选择，但产品名单不是硬编码门槛。

候选按以下信号排序：

- Google、Bing 或站内搜索存在明确需求。
- 出现可信的本币调价或全球排名变化。
- 与美国基准或历史价格存在可解释的显著差异。
- 税务、支付、账号地区或可用性具有真实本地信息。
- 数据覆盖、来源和更新时间达到发布要求。

P0-B1 已完成首轮只读筛选，候选及证据见
`docs/seo-price-events-country-pages-p0-b1-selection.md`。该清单已用于建立关闭式预览，但不代表页面获准索引或进入 sitemap。

### 4.2 路由

建议采用稳定且不与现有套餐 slug 冲突的路径：

`/{locale}/{category}/{product}/regions/{country}`

示例：`/zh/ai-pricing/chatgpt/regions/turkey`

国家页聚合该产品在当地已核验的活跃套餐；事件可以聚焦其中一个套餐，但 URL 不绑定短期套餐名称。

### 4.3 必备内容

- 当前本币价格、计费周期及价格采集日期。
- 与历史正式价格的变化，或明确说明暂无可信历史变化。
- 官方来源和证据日期。
- 当前汇率及汇率日期，明确区分本币调价和折算变化。
- 当地税务说明及可信等级。
- 账号地区、支付方式和当地可用性等订阅条件。
- 全球排名、美国基准和相邻价格地区比较。
- 基于事实的原创解释，不使用仅替换国家名的模板段落。
- 返回产品、相关套餐和官方入口的清晰路径。

### 4.4 当前实现状态

首批 7 个白名单组合已建立中英文关闭式预览，并完成桌面与 390px 手机宽度验收。页面直接读取现有正式价格、汇率、税务和来源证据，展示：

- 本币价格、美元参考、正式价格采集日期和精确 App Store 证据链接。
- 汇率快照、汇率日期及过期提示。
- 税务说明和税务可信度。
- 同套餐美国参考、全球价格位次和相邻价位。
- 已通过 A2 的本币调价前后值，或明确说明暂无达到公开门槛的调价。
- 每个国家独立的套餐选择、当地价格理解和订阅限制说明。

P0-C1 已在本地把其中 4 个组合提升为精确索引白名单；其余 3 个组合继续保持 `noindex,follow`，不进入 sitemap 或 hreflang。未在 7 个试点内的产品、分类和国家组合返回 404。Netflix 印度仍必须确认 Basic 对新用户的实际可用性。

## 5. P0-C：SEO 发布门禁

国家页进入 sitemap 前必须同时通过：

- 搜索需求门禁：存在站长平台、站内搜索或价格事件信号。
- 内容独特性门禁：包含该国家独有的价格、历史或本地背景。
- 数据完整度门禁：价格、来源、日期、币种和周期均可核验。
- 新鲜度门禁：正式价格和关键说明未过期。
- 异常门禁：不存在未解决的硬异常或套餐映射冲突。
- 预算门禁：不突破现有 sitemap 总量预算；达到上限时只提出调整建议，不自动替换现有 URL。

首批仅允许中文和英文索引。其他语言可以在内容完成后访问，但不得自动进入 sitemap 或 hreflang 集合。

### 5.1 P0-C1 只读发布体检

发布门禁已经实现为可重复运行的只读报告：

```bash
cd ai-price-site
npm run report:country-pages
```

报告使用只读事务，不写价格、税务、SEO 或审核数据，也不修改 robots、sitemap 或 hreflang。`--json` 用于留档；`--strict` 只在已获索引批准的组合重新出现阻断项时返回非零退出码，预览页自身仍被拦截不会阻止其他合格页面发布。严格检查已经接入 `preflight:full`。

2026-08-16 本地汇率同步后的体检结果见
`docs/seo-price-events-country-pages-p0-c-readiness.md`。7 个试点中：

- 技术与内容条件已满足：Claude 韩国、Grok 韩国、ChatGPT 菲律宾、Gemini 日本。
- 仍被税务复核拦截：Grok 泰国、ChatGPT 印度。
- 仍被税务及套餐可用性拦截：Netflix 印度。

### 5.2 P0-C1 精确索引白名单

2026-08-16 已在本地完成 4 个产品国家组合的精确开放：

- Claude 韩国。
- Grok 韩国。
- ChatGPT 菲律宾。
- Gemini 日本。

每个组合只生成中文和英文两个索引 URL，共 8 条。批准页共享同一份索引判断，metadata、hreflang、sitemap 和发布门禁不允许各自维护名单。Grok 泰国、ChatGPT 印度和 Netflix 印度继续作为可访问预览，不索引、不声明 hreflang、不进入 sitemap。

sitemap 增加独立地区页预算 `8`，本地预算结果为 `146/148`。本地浏览器已经验证批准页为 `index,follow` 且具有中英文 hreflang；阻断页为 `noindex,follow` 且没有 hreflang。该实现尚未提交或部署，不代表已经上线。

## 6. 转化和观察口径

复用现有事件接口和漏斗，不建设第二套统计系统。需要补充的维度：

- `landing_type=country_page`
- `product_slug`
- `country_code`
- 从国家页进入套餐页
- 从国家页访问官方网站
- 从国家页进入订阅条件或相关指南

上线后观察 14 至 21 天：

- 抓取和索引状态。
- 非品牌展示、点击、CTR 和平均排名。
- 国家页到套餐页和官方入口的转化。
- 页面是否触发数据纠错或用户疑问。
- 单页获得的搜索价值是否高于新增索引成本。

观察期结束前不自动扩大国家页数量。

## 7. Google Play 后续边界

没有套餐级证据时，只能展示：

- 最低公开应用内购买价
- 最高公开应用内购买价

只有 SKU、套餐名称或连续高可信证据能够建立准确对应时，才允许与 App Store 的具名套餐并列比较。独立边界视图可以作为 P2，但不得阻塞本轮 P0。

## 8. 实施顺序

1. P0-A1：只读价格事件候选查询和演练报告。
2. P0-A2：人工抽样并固定误报、去重和证据规则。
3. P0-A3：决定是否需要持久化候选表和后台候选视图。
4. P0-B1：依据真实信号选定首批 6 至 8 个国家页。
5. P0-B2：完成中文内容、数据门禁和桌面/移动端验收。
6. P0-C1：在预算内批准少量页面进入 sitemap。
7. P0-C2：观察 14 至 21 天后决定继续、调整或回滚。

## 9. P0 验收条件

- 只读演练不会把纯汇率变化识别为调价。
- 异常、过期和缺失数据不会生成可发布候选。
- 同一价格变化不会重复生成多个候选。
- 第一批国家页不超过 8 页，且不存在机械换词内容。
- 国家页未通过全部门禁时保持 `noindex` 且不进入 sitemap。
- 现有价格、采集、审核和前台页面不因候选系统而改变。
- 所有新增操作均有关闭或回滚路径。
