# V7 辅助页本地改版

类型：Improvement / L2。基线 `15edcbe2edc964985ce02357cb071555475761f4`（2.32.0）。

## 范围与不变项

- 关于、联系、隐私、条款、数据来源采用 Article 画布的 680px 正文与目录，移除价格侧栏。复用 GuideContents 与正文样式；独立薄组合 AuxiliaryArticle 不读取指南价格、不添加指南面包屑。
- 中文汇率工具及货币对页面采用 Tools 画布布局，保留现有金额、币种、汇率读取、换算、新鲜度判断和所有说明。正常值仅在用户交互时使用现有数字动画。
- 中文价格历史与快照采用统一面板、调价记录列表；读取器、过滤、120 天窗口、50,000 条安全上限及原快照链接均不变。
- 中文未知 URL 进入明确的 notFound 路由边界；错误页保留共用头尾，提供重试。未新增数据或测试路由到 sitemap。
- 法律/说明正文、H1、元数据、JSON-LD、正常页面原链接与顺序、联系 API 与字段校验保持不变。Plus、英文、数据库模型、缓存规则、19 个 isolate 文件不修改。

## 2026-11-13 产品负责人裁定

1. 历史页先保留现有本币观测和已确认调价记录，仅对齐布局与样式。缺少历史汇率序列，暂不展示人民币历史曲线或切换按钮；不以当前汇率回填历史，不称原始观测为连续走势。这是本轮批准的画布差异。
2. 仅中文 404／出错页可新增返回首页、搜索和现有产品建议入口。404 新增 `/zh/ai-pricing/chatgpt/plus`、`/zh/streaming-pricing/netflix`、`/zh/streaming-pricing/youtube-premium`、`/zh`；出错页新增 `/zh`。正常页面链接不改。

3. 自检发现旧工具对已过 7 天的汇率仍输出对照金额。产品负责人批准仅中文显示层在缺失/超过原上限时显示不可用；18 小时提醒、7 天上限、读取器、公式和英文页均不改。单测与浏览器测试覆盖新鲜、20 小时仍可用、10 天失效、缺失及无效金额。中文金额沿用此前已批准的全站格式化函数。

## 按页样式加载与性能验收

2026-11-13 产品负责人追加批准：仅本轮辅助页新增专用样式按辅助路由加载，保留颜色、字号、阴影和动效全部检查；字体策略、构建配置和性能门槛不变。

- public-components.css 恢复为基线原样。文章与历史/快照只加载各自的受检查样式，server-only 的 AuxiliaryStyles 读取固定仓库文件，不接受用户路径。文章目录代码只由文章组合引用，工具/历史页不下载它。
- 工具页加载 public/styles/v7-auxiliary-tools.css；文件内携带站内已批准的 Inter Tight 数字子集，字节与原 woff2 完全相同，700 字重、原 unicode-range 和 font-display:swap 均保留。没有增加/更换字体资产；执行型单测核对原字体字节，浏览器检查真实加载状态。只改变传输包装，不降低字体或性能要求。
- 404 组件在服务端可渲染，并通过客户端动态边界隔离状态样式；出错边界实际渲染时才加载本地状态样式。正常页面不请求状态 CSS，Plus 和英文不输出辅助样式。
- 五个专用样式文件全部加入原检查清单；执行型测试逐一构造颜色、字号、阴影和分散动效违规，必须拒绝，不增加豁免。
- 生产构建的文件追踪、路由资源清单、三轮冷缓存前后性能与失败尝试原始报告放仓库外复核包。正式结果以该包最终报告为准，单次诊断不代替三轮中位数。

最初新增公共样式使阻塞 CSS 从2个变4个，工具/历史页低于旧版；复用数字子集、单独预加载、直接内联工具字库均未单独解决差距，失败报告保留。最终同时去掉无关文章目录/状态代码依赖，并将工具样式与数字字体合并为按路由请求的一份资源。字体保持原字形与 swap；既有 V7 数字子集的小字号抗锯齿差异按此前批准记录。

## 交付边界

完整实现补丁、文件哈希、19个isolate对照、四态截图/录屏、原文及SEO链接对照、错误恢复测试和手机性能报告均放仓库外。检查以生产 build + start 为准，不仅运行开发模式。远端CI和生产环境尚未验证；本轮不提交、不推送、不合并、不部署。

自检补充：原中文 catch-all 在 Next 16.4.2 中调用 notFound 后，HTTP404正确但无脚本响应只有空壳；加Suspense虽然可读却会变成200，因此未采用。最终移除该catch-all，由根级404按现有x-pathname仅分流中文未知地址，其他语言仍返回当前Next自带的原404组件。新增无JavaScript真实404/可读性断言，并增加英文404四态逐像素对照；未更改proxy、框架配置或状态码门槛。框架原组件的内部导入随以后Next升级必须重跑此回归。

工具样式资源通过已有换算器模块的React preinit在SSR阶段声明（而非仅在RSC阶段发提示），因此无JavaScript也应有正确布局；测试直接验证文章680px宽、工具flex布局和对应stylesheet存在。普通页面不加载状态样式，英文不加载中文基础样式。

进一步精简：文章不携带联系表单规则，工具资源声明不再单独增加一个JS请求；两个状态入口复用同一错误边界代码包。所有规则与视觉保持不变，五份样式均执行原门禁和构造违规测试。

最终三轮交替冷缓存性能：说明文章、汇率工具、价格历史的新旧中位数均为97分，保持旧版门槛。原始报告和各次失败尝试保留在包内；没有降低字体策略、构建配置或断言。
