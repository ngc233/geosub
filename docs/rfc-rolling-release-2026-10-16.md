# 不停站构建与可回退发布

类型 Architecture / L3。用户批准本地实现与隔离预生产验证，禁止本轮推送、生产配置修改或部署。

目标：后台 2.12 大版本发布时，安装和构建不占用停站窗口，回退直接使用已保留的构建。公开 URL、SEO、内容准入、真实推广关闭及数据库恢复授权不变。

采用独立发布目录、双运行端口、OpenResty 受控 location include；正式 upgrade.sh / rollback.sh 分派 rolling-v1。旧 maintenance-v1 显式保留，不把旧脚本默认为低停机发布。首次接入必须先登记现有运行目录、构建与提交，并在经批准的生产窗口安装 include；缺少配置时拒绝发布。

每次升级固定干净远端提交、校验版本、独立构建，验证增量迁移兼容清单，暂停内容发布和定时器并等待在途任务结束，验证备份后迁移。候选健康及资源检查通过才原子更换入口，执行标准发布检查后记录版本。原进程和资源保留；失败恢复入口及任务路径，恢复之前开启的定时器，不能自动恢复数据库或重新打开内容发布围栏。

只允许明确审核的新增迁移；改动或删除既有迁移、未知新增迁移、回填均拒绝滚动发布。057 的新增推广表允许旧版并行。应用回退还必须通过现有内容回退围栏，不能绕过内容版本兼容保护。

资源采用共享只增不删目录，同路径不同内容直接拒绝。本版本不提供自动清理；磁盘不足拒绝升级，不靠删除回退点腾空间。最多保留当前和上一运行进程；历史文件保留。旧页面提交动作可要求刷新，绝不自动重放。

验收区分真实应用/OpenResty、正式编排脚本和 systemd/数据库工具的真实执行与替身测试。故障覆盖构建、迁移、健康、代理配置、切换后健康、重复回退和陈旧回退。最终结论以验收记录为准。

验收已通过，详见 [验收记录](rolling-release-acceptance-2026-10-16.md)。生产接入及公网回读属于获准发布后的操作，本轮未执行。
