# 匿名 PV 的内部与验收访问分类

类型：Improvement，L2；状态：随 2.10.0 在 `b5028bc` 部署，完成时间 2026-09-05T11:43:45Z。生产验收与回退记录见 [2.10.0 发布记录](release-versioning-2.10.md#2026-09-05-生产发布记录)。

## 用户问题与范围

运营人员需要区分产品访问变化与内部/验收流量。原有 `cookieless_page_views` 继续按原规则计数，后台和周报默认口径不切换。新增 v2 并行日聚合，用现有 `daily_stats` 存储，无 schema 迁移或历史回填。

每个被同源和路径校验接受的请求，在同一事务中写入原口径的 global/page 计数，再写入恰好一个 v2 分类的 global/page 计数：

| 分类 | metric_key | 含义 |
| --- | --- | --- |
| eligible | cookieless_page_views_eligible_v2 | 当前浏览器未报告已知排除信号；不是已验证真人 |
| internal | cookieless_page_views_internal_v2 | 浏览器保存了未过期的内部访问排除标记 |
| automation | cookieless_page_views_automation_v2 | WebDriver 或受控验收请求明确标记 |
| unclassified | cookieless_page_views_unclassified_v2 | 旧客户端、未知版本/分类、标记损坏或无法读取浏览器存储 |

版本为 `page-view-population.v2`。启用日是发布后的首个写入日，必须从发布记录确定；启用当日不作为完整比较日。新旧口径按日分别聚合，v2 四类之和应等于同日启用后接收的原口径计数。启用首日原口径还含发布前流量，不能据此误报不一致。

## 排除信号和隐私

通过现有服务端管理员认证后，后台挂载一个不渲染 UI 的组件，向本浏览器 localStorage 写入 `geosub_measurement_internal_until`。值只有按 UTC 日期计算的30天到期日，不含账号、随机标识或会话。每次进入后台刷新有效期；退出登录不会马上把团队浏览计为候选公共访问。清除浏览器站点数据可移除标记，过期后不再排除。

普通访客不新增存储值。计数请求继续 `credentials: omit`，仅上传路径、版本及固定分类枚举；不读取管理员 cookie、不查询管理员身份、不存储 IP、User-Agent、标记到期日或访问明细。无法读取存储的浏览器保留在 unclassified，不默认算作 eligible。

WebDriver 优先归入 automation。受控 HTTP 验收可以添加 `x-geosub-measurement-traffic: automation`；它仅决定该请求的聚合分类，不授予权限，仍须通过同源与路径校验。浏览器分类为自报信号，不能证明真人，也不是反作弊机制。未访问后台的团队浏览器、清除标记后或未暴露 WebDriver 的自动化仍可能计入 eligible。

## 验收与回退

- 正常公共导航同时产生原口径与 eligible；内部和自动化只进入各自 v2 排除分类，旧口径仍保留。
- 旧版、错误版本、损坏标记、存储拒绝均不进入 eligible。
- 跨域、超长请求、无效路径不写任何计数；一次请求只属于一个 v2 分类；全站与页面计数在同一事务更新。
- 不记录任意客户端附加字段、身份或原始请求内容。
- 无新增用户可见控件、页面、SEO 或缓存行为；认证方式和默认分析同意设置保持原样。
- 代码门禁包含相关测试、类型、Lint、生产构建；发布前补充真实浏览器/数据库验收，发布后记录启用时间并核对首个完整 UTC 日。
- 回退到上一应用提交即可停止 v2 写入，原 PV 与已有报表继续运行；保留 v2 历史数据，不删除或合并。后续重启 v2 需记录中断日期，不能当作完整连续窗口。

## 使用门槛

先并行观察分类覆盖率、unclassified 占比与新旧差异。不能将 eligible 直接命名为“真实用户”，也不能拿它与旧口径做增长环比。后台和周报切换到新口径属于后续独立决定，必须注明排除范围、启用日期与完整比较窗口。

## 2026-09-05 本地验收证据

- 全量测试614项通过，包含13项新增分类/真实POST处理器测试；类型、Lint和生产构建通过。
- 从已验证备份恢复的专用本机数据库中，20个并发请求使旧PV增加20，四类v2各增加5；故意拒绝v2写入时，整个请求的旧/新计数均回滚；跨域请求不写入。
- Chrome实际导航并登录隔离测试管理员：进入后台后访问公开页，旧PV与internal各增加1，eligible不变；退出后再次访问得到同样结果。未使用真实生产账号或改变生产状态。
- 本轮组件返回null，不新增可见UI、样式、控件或动画；四态视觉矩阵不适用。真实浏览器验收覆盖受影响的导航/计数行为。Safari/WebKit未验证，生产验收未执行。
- 本机处理器加数据库各20次顺序样本：旧实现p50/p95约1.69/2.25ms，新实现约2.82/3.47ms。每次接收请求的upsert从2次增至4次；这些是本地直接调用的诊断值，不代表生产HTTP延迟或吞吐能力。发布观察须补生产响应时延与数据库负载。
- 默认后台和周报仍只读旧metric_key，现有日聚合脚本只更新自身明确列出的事件指标，不把新分类混入旧PV。
