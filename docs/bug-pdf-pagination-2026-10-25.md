# 报告空白尾页与页脚修复

Bug / L2；用户已批准推送并在 CI 通过后按 L3 标准流程仅发布网站。

现象：英文及部分语言报告在所有内容页后追加只有页码的空白页，页眉重复叠印。根因：PDFKit 显式 width 会启用 LineWrapper，即使 lineBreak=false；794pt 页脚基线加字体行高超过正文下界时自动新建页面。续页原先绘制页眉，最终遍历又绘制一次。

范围：共享 PDF 渲染器的分页与页脚；页码按测量宽度计算右对齐坐标，固定文字不传 width，不进入正文排版流；页眉只在最终遍历时统一绘制。先用真实 PDF 回归复现，覆盖12语言、无地区、两套餐短报告和大量地区续表；实际提取校验每页正文、连续页码、页脚边界、价格/来源/快照未丢失，渲染检查。

不变项：canonical 报告数据与标题、价格/审核逻辑、页面和中文Plus实验、字体/依赖、缓存/路由/索引政策、数据库输入、采集组件/任务/定时器。只修缺陷，不重新设计报告。

发布：候选2.15.9；完整release-check、CI及真实报告验收后，标准geosub_ops.py网站滚动升级。数据库输入不变时跳过迁移与全量任务暂停。登记精确2.15.9→当前2.15.8内容契约兼容对，保留旧构建；发现未知连接结果仅查原请求。上线核对各语言报告及代表多页产品，价格和标题保持同一数据快照；自然采集变化单独用记录解释，不手工冻结或回填数据。

本地验证：修复前36项真实PDF用例中24项复现错误，修复后36项全过；完整release-check通过，805项前端测试通过。另对12语言短报告和100行续表共24份/132页实际提取：每页有正文、连续页码、页脚在纸面内且每页仅一份页眉，100行完整无重复/丢失，输入数据逐字节不变。12语言短报告48页已渲染，中文/英文/阿拉伯文/德文代表全页目视核验；生产所有语言报告仍需上线后验收。
