# DATA-2 / 首页最近变价：本地任务说明

Feature / L2，基线 1da247e9d881706ae9a9c0488f6c4578f6eac8cf（2.28.2）。产品负责人选择按原顺序补齐首页最近变价；本轮仅本地实现与自检，不提交、推送或部署。

- 数据规则复用 getPriceChanges：批准、置信度、来源、同币种本币标价与计费周期不变，保留异常/待审记录作为连续性中断。不是汇率或最低价的变化。
- 变价发生时间限定最近30天，最新最多6条，缓存3600秒且命中后再次检查30天边界。沿用产品历史120天证据窗口，以便取得窗口前基准及 ignored 同价桥接；不把120天内所有事件展示为最近30天。
- 只读一致性事务。仅读取有最近30天已批准端点的序列；每页5000、最多50000条，超限整个区块隐藏并记录安全事件。缓存仅含最多6条展示DTO，原始观察不进入客户端或缓存。
- 无合格记录、读取失败或超限时隐藏区块；失败仅记录事件名和错误类型。全局数据不可用不影响页面其他区域。
- 视觉标准是 design/canvas/source/Home.dc.html 和 README：分类区右侧、28px圆形趋势图标、本地日期、涨跌数字、真实历史链接；文字明确本币标价，不随显示币种改变百分比。
- 首页H1、导语及所有SEO元数据保持不变；新增的价格历史链接属于本次区块所需入口。中文Plus、英文页面、采集器、数据审核、服务器、19个isolate文件不改。
- 验收：单测含30天边界、最多6条、异常中断、ignored连续性、空态/超限、货币与来源变化；生产build+start四态与键盘测试、空数据隐藏、Plus/英文8组截图对比及SEO对比。
- 回退：移除该首页区块及读取入口，数据库无迁移；不涉及生产回退操作。查询规模只在本地测试验证，生产性能尚未验证。
