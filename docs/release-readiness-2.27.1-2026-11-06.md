## 范围与不变项

- DATA-1 汇率查询合并价格原币种和 PublicCurrencySelect 共用的 supportedDisplayCurrencies；不额外增加查询。即使价格为空或均为 USD，仍读取显示币种。价格 SQL 筛选与原哈希不变。
- 18 小时新鲜度、有效性判断、缺失/过期回退 USD 及提示不变。共享缓存仍一小时、原失效标签不变；缓存键升为 v3-display-currencies，防止跨部署复用缺币种的旧缓存。
- 新版中文节省率统一四舍五入为整数；排序、中位数、比较个数使用未取整原值。国家卡正值“便宜 X% 以上”改为“便宜约 X%”，避免四舍五入向上后作精确下限承诺。H1、导语、SEO 元数据与内链不变。
- 仅新版中文命名函数增加 Membership → 会员、Subscription → 订阅会员；存储的中文优先，品牌名和旧版/英文命名函数不变。
- 不改数据库结构、价格数据、采集程序、调度器或审核规则。陈旧价格诊断使用独立只读报告。
