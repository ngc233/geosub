# 服务端浏览量筛选与疑似爬虫分流

类型：Feature / L2。状态：本地验证完成；2026-11-04 获准推送、部署及上线核验，发布进行中。

## 目标与范围

2026-11-03 用户批准补充服务端识别，并在流量看板独立显示疑似爬虫、从正常浏览量排除。旧 v2 的 eligible 只代表未自报排除信号，不代表真人。本次增加 v3 并行日聚合，使用现有 daily_stats，不迁移 schema、不回填或删除历史，不改变公开页面、SEO、访问权限或页面可达性。原始和 v2 计数继续保留，旧报表不静默切换。

## 分类契约

同源、路径和大小验证通过后，原始、v2、v3 的 global/page 计数在同一数据库事务递增，共六项 upsert。v3 恰好属于 eligible、suspected、internal、automation、unclassified 中一类，键为 cookieless_page_views_<分类>_v3。内部、自报自动化和未知保留原排除分类；原 eligible 再经过服务端筛选。客户端不能声明 v3 eligible 来绕过服务端判断。

疑似信号包括：明确的爬虫/自动化/命令行 UA 标记；与本站 fetch 计数方式矛盾的浏览器请求头；同一可信代理来源与 UA 的60秒窗口超过120次、同时覆盖至少30条路径。阈值前的请求不追溯改写。普通 Chrome/Firefox、旧浏览器、缺少可选请求头、语言、地区以及单独共享 IP 均不构成判定依据。只分流统计，不拒绝访问、不返回封禁响应。

频率状态只存在单进程内存中，IP+UA 和路径使用随机进程密钥的 HMAC，最多10000个来源、每来源最多30个路径摘要，窗口60秒，定时清理最迟再过60秒，进程退出即丢失。无明文 IP/UA/路径、Cookie、持久身份或请求明细写入数据库；数据库只保存日聚合及固定版本/分类元数据。可信代理头沿用 client-ip.ts，未知/非法来源不进入公共共享桶。上线前验证代理覆盖 x-real-ip，配置 cf-connecting-ip 时必须确认入口只信任 Cloudflare；不相信客户端任意 X-Forwarded-For 首项。

限制：UA/头可伪造，单进程阈值会被多实例、换IP、低频完整模拟浏览器绕过。该分类是疑似自动化，不是已确认恶意，也不是全站真人统计。11月3日分布式流量不能仅凭本次代码宣称已全部识别。

## 看板与历史边界

主 PV 改读 v3 eligible，“疑似爬虫”读 v3 suspected；趋势、日表和 CSV 使用同一口径。未启用日期显示缺失而非0。启用当天只展示已筛选部分，并显示尚未筛选原始计数；跨缺失日期的周期总计不冒充完整周期。原始总量、已筛选量与其他排除量用于核对；没有筛选覆盖的历史不推断正常/爬虫。覆盖不完整时关闭增长百分比及上期对比，样本UV/会话维持原有同意统计范围，不能和PV直接相除。

## 验收与回退

验收覆盖普通浏览器、WebView/无可选头、明确爬虫、矛盾头、突发/共享来源、阈值与过期、容量、非法代理头、同源拒绝、事务失败；SQL用隔离本机临时表验证各类和日/周期对账、首日部分覆盖、回退中断、旧快照和缺失；后台桌面/390px明暗、键盘、展开、导出、空态/错误态；完整测试、类型、Lint和生产构建。

回退应用停止v3写入，保留原始/v2/v3数据，不执行历史回填。重新启用产生的覆盖缺口必须继续显式显示。部署需遵循RELEASE.md并记录实际启用UTC时间；观察首个完整UTC日分类和原始计数对账、响应延迟/5xx及数据库负载。上线前不声称已过滤生产流量。
