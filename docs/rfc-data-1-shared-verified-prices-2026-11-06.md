# DATA-1 共用核验价格读取与代表套餐

类型：Architecture / L2。基线 `1c0492821b25d21fe11ce19bc8b4867dc69b6efe`。2026-11-06 产品负责人已审核集合口径、汇率处理、排除原因、中位数算法，确认 34 项代表套餐并批准正式 PR；不合并、不部署。

## 目标与裁定

V2 第 8.1 节要求未来首页统计、地图与国家榜共用价格来源。把原 `getCountryHub` SQL 提为服务端读取器，只移除国家限制，其他发布、证据、平台、周期、同价确认条件逐字不变。

国家页保留汇率失效时的本币价格（`usd=null`）；共用一次读取，另派生有效美元集合供首页使用。没有美国同套餐价的有效美元行仍属于集合；需要美国基准的代表套餐则要求有美国价及至少 10 个不同地区，不伪造基准、不替换套餐。

代表规则：“选官网主推、大多数人会买的个人月付档；覆盖 ≥10 个地区即合格，覆盖多少不作为首要依据。”负责人确认的 34 项逐项写入 `homepage-representative-plans.ts`；Boomplay 没有美国价，不写入代表配置，但不从 D1 完整集合删除。

## 实现边界

- `readVerifiedPriceSource` 一次冷读最多两条 SELECT：价格一条，涉及的非美元汇率一条；美元或空集合只需一条。
- `loadVerifiedPriceSource` 使用既有 Next Data Cache 缓存快照 3600 秒，沿用价格/汇率失效标签及本地预览键隔离。React cache 在同次服务端渲染内复用结果和失败，不再分别建立每国数据库缓存。
- `getVerifiedPriceRows` 集中原核验、汇率、美国基准投影。国家页再按国家过滤；`loadComparablePrices` 派生有限且正数的美元行。每次投影重查价格与汇率新鲜度，不因缓存而放行过期汇率。
- `getHomepageRepresentatives` 只校验配置中的产品和套餐；套餐消失、无有效美国价、地区不足 10 均排除，其他套餐再合格也不替换。不同地区去重计数，美元原值不取整。
- 服务端 `loadHomepageRepresentatives` 返回合格代表并记录 `configured-plan-ineligible` 日志，仅含公开 slug、原因、地区数；相同问题每进程每小时最多一次，状态变化和恢复后复发立即记录。候选报告也只标记负责人配置，不再按覆盖自动推荐。
- V3 首页产品展示须使用这一受校验入口，日志在入口被读取时触发。本 PR 不接入首页 UI、统计文案或新增链接。D1 统计与国家页继续使用完整集合，不受代表配置过滤。
- 国家页文案、取整、美国基准及排序不变；保留页面 1800 秒 ISR。共享读取缓存为批准的 1 小时；Next 时间重验证可能后台更新旧快照，不宣称是严格的一小时事务快照，已有失效标签仍可提前刷新。
