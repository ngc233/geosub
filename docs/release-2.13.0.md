# 2.13.0 软件订阅套餐入库能力

状态：本地发布候选；尚未推送或部署。

## 范围

- 后台可创建草稿套餐、修改名称与排序，并在安全边界内修正状态或归档错误候选套餐。
- 软件产品缺少人工维护的套餐映射时，App Store 采集在写入套餐和价格观测前停止，避免把一次性商品或本地化名称当作新套餐。
- 保留 AI 和流媒体的现有采集行为；不发布 Canva、Notion 或任何未核验价格。

## 变更属性

- 无数据库迁移、生产 SQL、批量回填或定时任务改动。
- 无公开软件分类页、导航、sitemap、canonical 或结构化数据变更。
- 生产发布仍使用标准 `upgrade.sh` 流程，`GEOSUB_RUN_BACKFILLS=false`。

## 已完成的本地验证

- `tsc --noEmit`、套餐页 ESLint 通过；功能改动后的 `next build` 通过。仅修改版本号后的重复构建在本机长时间停留于编译阶段，已停止，部署前仍须在正式门禁中再验证构建。
- 采集器可靠性测试 6/6 通过；全量 Node 测试 721 项中 718 项通过。其余 3 项受本机缺少 `pwsh` 和 `@next/eslint-plugin-next` 影响。
- 版本同步检查通过：`2.12.1 -> 2.13.0`。

## 发布门禁与回退

- 推送后须通过远端 CI，并在可用的 PowerShell 环境执行 `scripts/release-check.ps1`。
- 部署前须按 `docs/RELEASE.md` 完成隔离环境与桌面、移动、暗色的后台编辑验收；目前本机没有隔离测试数据库，不能宣称这些门禁已通过。
- 部署后核对新增、编辑、归档的审计日志，以及无套餐映射的软件采集失败提示；不运行无关回填。
- 如需回退运行时代码，使用 `docs/RELEASE.md` 指向的标准 `rollback.sh` 和明确部署 ID。应用回退不会自动更改后台人工编辑过的记录；本次没有自动数据迁移。
