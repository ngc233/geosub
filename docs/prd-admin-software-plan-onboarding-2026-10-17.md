# 软件订阅套餐入库补丁

状态：本地实现，待验证与发布。工作类型 Feature，风险 L2（后台写入、采集规则）。

## 用户问题与证据

新增 Canva、Notion 草稿后，现有后台没有套餐创建或纠错入口。App Store 任务在缺少 canonical plan spec 时按商品名称创建套餐：Canva 产生 20 个套餐，含婚礼邀请函、母亲节素材与已停止向新用户提供的 Teams；Notion 产生 4 个套餐，含同一 Business 的多语言名称。两者均无正式价格，产品保持草稿。

## 本补丁范围

- 管理后台创建草稿套餐、编辑名称及排序、检查周期和状态、归档无正式价格的错误套餐。
- 软件产品缺少维护的 plan spec 时，App Store 采集在写入套餐和价格观测前停止并报告明确原因。
- 保留现有 AI、流媒体的采集和公开路由行为。

## 不变项与后续步骤

- 本补丁不发布 Canva、Notion，不提升任何价格，不批量删除或改写生产记录。
- 官网与 App Store 分属不同计费渠道；本补丁不混算来源。
- 软件公开分类页仍保持未发布状态。独立路由、canonical、sitemap 和导航需在正式价格与内容质量达标后另行验收。
- Canva、Notion 的 App Store 套餐映射应在官方来源核对后加入 canonical spec；既有错误套餐再通过后台逐项归档。官网采集与 Web 审核规则为独立后续工作。

## 验收与回退

- 无 spec 的软件采集不能新建套餐或观测；已配置的 AI、流媒体采集路径不变。
- 新套餐只能以草稿建立；有观测后不能改 slug 或周期；已发布产品或已有正式价格的套餐不能从该后台入口归档。
- 后台保存必须鉴权、记录审计、检测并发版本、提供失败反馈；明暗与桌面移动视图均可使用。
- 发布后只验证改动影响的后台流程与采集日志。回退应用代码不自动恢复数据；本补丁没有迁移或自动回填。

## 本地验证（2026-10-17）

- `tsc --noEmit`、套餐页 ESLint、`next build`、采集器可靠性测试（6/6）通过。
- 全量 Node 测试 721 项中 718 项通过。其余 3 项因本机缺少 PowerShell（2 项）和 `@next/eslint-plugin-next`（1 项）未通过；不是本补丁断言失败。
- 本机没有接入隔离测试数据库，也没有运行生产采集器；上线后仍需在后台验证新增、归档和无 spec 采集失败提示。
