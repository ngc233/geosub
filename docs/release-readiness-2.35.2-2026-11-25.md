# GeoSub 2.35.2 发布准备

发布分支基于 #106 合并后的 `main`（`e75a771e4cfd9e72f2b83272bf2cb28fad0fa972`）。版本从主线的 2.35.1 递增至 2.35.2。2026-11-25 公网健康端点实际报告 2.35.0（`3bb1372ac8e7e2c07c46c444df6f7ec13859be5f`）。正式上线前，以源站身份和可用保留构建复核为准。

## 发布范围

- 中文产品总览和非 Plus 套餐详情在大屏恢复左侧导航，手机和中屏在页首切换产品。保留原有链接目标、价格口径和 SEO 元数据。
- 搜索结果补充品牌图标，首页和套餐页统一展开按钮。币种弹窗关闭按钮保持正确宽度，套餐分布图保留真实价格位置，相近地区可从分组入口选择。支持触屏、键盘与减少动态效果。
- 本 PR 只改五个版本文件、CHANGELOG、本记录和精确回退登记。依赖版本与 #106 合入后的主线一致。19 个受保护文件保持逐字节一致。

## 数据库与回退

- 相对公开运行的 2.35.0，正式 SQL 和 Prisma 迁移输入相同。部署前核验生产账本及 schema 062 已登记，数据库输入确认一致后，标准升级应记录 `migration_skipped`。店铺扩展 SQL 属于隔离任务，采集器发布、扩大试点和数据回填各自走独立流程。
- 35 个正式读取契约文件中仅 `VERSION` 变化。候选指纹为 `bb7be3c43199b8c41a58473d1a06cb873cadea0f29968aa6d828fadd5c96265c`，2.35.1 主线指纹为 `c9d124847f516acd7dab6d04076d76f466cbeaef50d85c6fe0df9b77b0752faa`。
- 保留 432 条既有记录。沿用 23 条已审核的精确回退对，再追加一条精确指向合并后的 2.35.1 主线，保留原有读取目标和事实授权。线上 2.35.0 对应指纹 `d23516d49eeb27f7245b061613a9672943878888693002176ee51203a7a434f9`，已在继承目标内。上线前核实实际保留的 2.35.0 构建，应用回退使用该保留构建。
- 兼容登记变化需要按手册安装最终合入 `main` 且 Push CI 成功的正式控制器。安装前后逐一核对 86 个文件，安装后与最终 SHA 的归档字节一致。预期 `rolling-content-compatibility.json` SHA-256 为 `1f8fde0e832c1cf44b149df0cac5412225746f701b3b257e752c10f47b9d66e6`。

## 验收顺序

1. 原样执行 `scripts/release-check.ps1 -BaselineRef origin/main` 和独立 PostgreSQL 16 迁移兼容测试。核对发布范围、历史登记、版本文件与审计结果。
2. 完成发布 PR 的 Push 与 PR CI，合并后核对最终 `main` 完整 Push CI。按批准的发布窗口复跑生产只读数据门禁，核对当前线上和回退点，再按手册安装控制器及滚动升级。
3. 完成五分钟观察并记录原生回执、部署开始时间、源站与公网生效时间。复验产品总览和套餐详情的桌面、手机明暗状态，检查导航、地区分组、币种选择、Plus 两种实验分流和英文代表页，以及 SEO、sitemap 和现有价格。

标准 `release-check.ps1 -BaselineRef origin/main` 通过，含 1,219 项单测通过、1 项既有跳过、生产构建通过及 Linux 控制器 56/56。独立 PostgreSQL 16 迁移兼容测试 16/16 通过，覆盖旧客户端、合成数据恢复、失败原子性和回退账本。依赖审计前端为 0 high、0 critical、8 项既有 moderate，后端零告警。本地验证使用测试数据，生产数据门禁留到批准的发布窗口。
